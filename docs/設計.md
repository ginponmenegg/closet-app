# 服管理アプリ 設計(案)

アフィリエイト会社(`affiliate-Company`)とは無関係の別プロジェクト。

## 目的
- 服の重複・似たデザインの購入を防ぐ
- 買い物中にサイズを確認できる

## 決まっていること(2026-10-26 回答)
| 項目 | 内容 |
|---|---|
| 規模 | 100〜200着 |
| 利用者 | 2人。**管理は別々、相手の服は閲覧のみ** |
| 端末 | 両者iPhone(iOS 27.0.1) |
| 店内の主用途 | 持ち服の一覧確認(自動で似た服を探す機能は不要) |
| 記録項目 | 写真、サイズ、ブランド、購入店、購入時期 |
| 登録の手間 | 1着につき写真1〜2枚で済ませたい |
| 費用 | 0円。クラウドの無料枠は可 |

## 方式:PWA
Macが無い(Windows)ので、ネイティブiOSアプリは作れない。Webアプリを作り、
Safariで開いて「ホーム画面に追加」するとアプリとして使える。

## 画面
1. **一覧**: 写真グリッド。上部に [自分 | 相手] 切替。絞り込みはカテゴリ・ブランド・サイズ
2. **詳細**: 写真、全項目。自分の服のみ編集・削除可
3. **登録**: 撮影 → カテゴリ → ブランド / 購入店 → サイズ → 購入時期(任意) → 保存。保存後すぐ次の撮影へ進める連続登録モードあり
4. **ブランド別サイズ**: ブランドを選ぶと、持っているサイズが一覧で出る(サイズ確認用)

## 写真は2枚まで
- 1枚目: 服の全体
- 2枚目(任意): タグ・ラベル。サイズ表記の確認用
- 端末側で長辺1024px、JPEG品質0.7程度に縮小して保存する。
  1枚約150〜250KBとして、200着×2枚でも約60〜100MBの見込み(実測前の概算)

## データ
```
clothes
  id            uuid
  owner_id      uuid       ← 所有者
  category      text       ← トップス / ボトムス / アウター ... (選択式)
  brand         text       ← 過去入力から候補表示
  shop          text       ← 同上
  size          text       ← S / M / L / 数字 / 自由入力
  purchased_on  date       ← 年月のみで可、任意
  photo_main    text       ← 保存先パス
  photo_tag     text       ← 任意
  memo          text       ← 任意
  created_at    timestamptz
```
権限: **誰でも閲覧可、書き込みは所有者のみ**(行レベルセキュリティで実装)。

## 構成(無料の範囲)
| 役割 | 候補 | 備考 |
|---|---|---|
| 画面 | 素のHTML/CSS/JS(ビルド不要・依存ゼロ) | 実装済み。ファイルを置くだけで公開できる |
| ホスティング | Cloudflare Pages または GitHub Pages | GitHub Pagesは無料だと公開リポジトリが必要 |
| DB・認証・写真 | Supabase 無料プラン | 容量・休止条件は変わるため**契約時に公式で確認** |
| 店内の表示 | 一覧とサムネイルを端末にキャッシュ | 電波が弱くても**閲覧**はできる |

## 注意点
- Supabaseは無料プランだと、一定期間アクセスが無いとプロジェクトが休止する可能性がある(**要確認**)。
  週1回開けば防げる想定
- 万一に備えて**JSON書き出しボタン**を付ける(月1回のバックアップ用)
- オフライン時の**登録・編集は初版では対応しない**(閲覧のみ)
- キーは公開用のものだけをコードに置く。**管理用キーはリポジトリに入れない**
- iOSがWebアプリの端末内データを消す場合がある(**要確認**)。正本はクラウド側に置くので、消えても再取得できる
